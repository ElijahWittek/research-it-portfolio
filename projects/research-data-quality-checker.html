Data Quality

Research Data Quality Checker

A local command-line application for formal and rule-based validation of structured meteorological research and measurement data stored in CSV files.

Back to Projects

Problem

Structured measurement data can contain missing values, invalid numbers or dates, duplicate identifiers, and values outside predefined plausibility ranges. These issues should be identified before the data is processed further.

The project focuses on formal data quality checks. It does not assess the scientific correctness of individual measurements.

Solution

The application reads one local CSV file per run and validates it against a fixed schema and a documented set of rules. Validation findings are collected in a structured form instead of stopping after the first detected issue.

After validation, the application displays a compact terminal summary and creates a detailed UTF-8 text report.

Key Features

  • Validation of required CSV columns and missing required values
  • Validation of numeric values and calendar dates
  • Detection of duplicate measurement identifiers
  • Validation against fixed plausibility ranges
  • Collection of multiple findings in one run
  • Terminal summary and detailed text report

Technical Structure

The application is divided into small modules with clearly separated responsibilities:

  • main.py coordinates the command-line workflow and handles file errors and exit codes.
  • csv_reader.py reads the input file.
  • validation.py contains the individual validation rules and dataset validation logic.
  • report.py creates the terminal summary and detailed validation report.

The completed project contains 44 automated pytest tests. Ruff completed without findings in the final project state.

Installed command:

research-data-quality-checker <csv-file>

Known Limitations

  • The CSV schema is fixed.
  • Plausibility ranges are predefined project rules.
  • Only one input file is processed per run.
  • Detected issues are reported but not corrected automatically.
